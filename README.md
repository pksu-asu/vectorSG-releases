# VectorSG — анализ режимов синхронного генератора с помощью векторных диаграмм

Программа для лабораторной работы «Анализ режимов синхронного генератора
с помощью векторных диаграмм» (дисциплина «Переходные процессы в
электроэнергетических системах»). Заменяет DOS-программу `vector.exe`.

Все величины — в относительных номинальных единицах, углы — в градусах.

## Расчёт

Установившийся режим без учёта активного сопротивления статора:

```
Uq = Uc·cos δ        Ud = Uc·sin δ
Iq = Ud / Xq         Id = (Eq − Uq) / Xd
I  = √(Id² + Iq²)
P  = Ud·Id + Uq·Iq   Q = Uq·Id − Ud·Iq        S = √(P² + Q²)
φ  = arctg(Q / P)    cos φ = P / S            Ia = P / Uc,  Ip = Q / Uc
E''q = |Uc + jI·X''d| = √((Uc·cos φ)² + (Uc·sin φ + I·X''d)²)
```

Для неявнополюсного генератора (Xd = Xq) это совпадает с формулами
(1.5)–(1.12) методических указаний; при Xd ≠ Xq учитывается явнополюсность.

Угловая характеристика: `P(δ) = Eq·U·sin δ / Xd + U²/2·(1/Xq − 1/Xd)·sin 2δ`.

## Управление

| Клавиша | Действие |
|---|---|
| ↑ ↓ | э.д.с. возбуждения Eq (шаг 0,1; Shift — 0,01; Ctrl — 0,2) |
| ← → | угол нагрузки δ (шаг 1°; Shift — 0,1°; Ctrl — 10°) |
| + − | напряжение сети Uc |
| PgUp PgDn | масштаб диаграммы |
| Enter | записать текущий режим в таблицу |

Значения также можно вводить в полях слева. Кнопки «Подобрать δ по P» и
«Подобрать Eq и δ по P и Q» задают режим по мощности (например, номинальный
Pн = 0,8, Qн = 0,6). Таблицу можно скопировать в Excel или сохранить в CSV.

Если клавиши не действуют — щёлкните по диаграмме (фокус уходит из поля ввода).

## Сборка

Lazarus 2.2+ / FPC 3.2+, пакет LCL. Открыть `VectorSG.lpi` и выполнить
«Запуск → Собрать» или в консоли: `lazbuild VectorSG.lpi`.
